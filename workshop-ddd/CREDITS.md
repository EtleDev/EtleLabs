# Crédits

Le workshop Domain-Driven Design dont ces supports dérivent est celui d'**Ancyr
Academy**.

- Déroulé original sur 7 sessions : `ancyr/cours1.html` … `ancyr/cours7.html`
- Exercices et devoirs de référence : `ancyr/exercices/` et `ancyr/homeworks/`
- Base de code des devoirs : <https://github.com/Ancyr-Academy/wk-ddd-2025April29>
  (TypeScript, vitest, pnpm)

Les énoncés des devoirs reproduits dans `ancyr/homeworks/` proviennent du
`README.md` de ce repo. Les exercices de séance de `ancyr/exercices/` ont été
reconstitués depuis le board Miro de la session du 29 avril 2025 et les decks
originaux.

Le découpage sur 5 séances (`exercices/`, `homeworks/`, `docs/partie-*.html`) est
une adaptation d'Etienne Leconte.
