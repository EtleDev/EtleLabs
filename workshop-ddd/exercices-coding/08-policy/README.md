# Exercice 8 — Faire émerger la policy

> Pendant en code de [`exercices/08-policy/`](../../exercices/08-policy/).

## Consignes

Implémenter les règles métier **une par une**, dans l'ordre où l'animateur les
donne. Ne pas lire la suivante avant d'avoir fait passer la précédente.

À chaque règle : écrire le test, le faire passer, **puis** se demander si le
design tient encore. Le but n'est pas d'arriver au pattern — c'est de voir à
quel moment précis il devient nécessaire.

Durée : 20-25 min.

## Règle 1 — c'est tout ce que vous savez pour l'instant

> Calculer le prix d'un voyage. Prix = distance × 100.

Le code de départ l'implémente déjà. Les règles 2 à 5 arrivent en séance.
